\section{Dataset scope}

The template covers Electricity, Traffic, Solar-Energy, Weather, Exchange
Rate, ETTh1, ETTh2, ETTm1, and ETTm2; PEMS is excluded. Each panel is converted
once into TIME's multivariate saved-Arrow representation. Source configuration
controls targets, exclusions, aggregation, and missing-value handling.

\section{Shared supervised contract}

Children will train only on chronological training observations, select models
using validation observations, and evaluate on held-out test windows. The
split borders, horizon set, lookback lengths, sampling stride, target mode,
objective, and seed grid remain intentionally unspecified because they define
the scientific comparison and must be selected before training code is added.

\section{Ownership}

This repository owns reusable classic-data preparation and loading. Descendant
repositories own TimeTensors-, RevIN-, PatchTST-, DLinear-, or other scientific
experiments and retain their own logs, outputs, reports, and conclusions.
